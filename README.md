
# CodeAlpha Task 2: Smart Stock Portfolio Tracker

## Project Overview
A Python-based application that helps users track their stock investments using predefined stock prices. It calculates individual stock values and total portfolio investment.

## Features
- Display available stocks and their prices
- Add stocks using stock symbols and quantities
- Calculate individual investment values
- Display total portfolio investment
- Validate stock symbols and quantities
- Export portfolio reports to CSV files
- Display a menu-driven interface

## Technologies Used
- Python
- Dictionaries
- Functions
- Conditional statements and loops
- CSV file handling
- Basic arithmetic

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python stock_tracker.py

## How to Use
1. Select option 1 to view available stocks.
2. Select option 2 to add a stock.
3. Select option 3 to view the portfolio.
4. Select option 4 to export a CSV report.
5. Select option 5 to exit.

## Output
The application displays the total investment value and saves the portfolio report as `portfolio_report.csv`.
